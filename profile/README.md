## 關於公會

中華民國第三方支付服務業商業同業公會（以下簡稱「公會」）由國內第三方支付服務業者組成，致力於促進產業自律、健全支付環境，並作為會員、主管機關與社會大眾之間的溝通橋梁。

公會相關資訊、最新消息與入會說明，請參閱 [公會網站](https://www.tpfa.org.tw)。

## 這個 GitHub 是做什麼的

這裡是公會的官方 GitHub 組織，用來提供 **會員公司技術人員** 串接公會平台所需的技術文件與工具，例如：

- 會員資料 API 的串接規格與說明
- 各程式語言的範例程式與測試工具
- 版本更新紀錄與異動通知

除本頁之外，組織內的技術文件 **僅限受邀之會員技術人員閱讀**，不對外公開。

## 我是會員公司的工程師，要怎麼取得文件？

1. **請貴公司的會員代表提出申請**
   由會員代表登入公會會員平台，申請將您設為貴公司的「技術窗口」。
2. **公會審核**
   秘書處確認申請人身分與用途後核准。
3. **收到 GitHub 邀請**
   核准後，您會收到一封 GitHub 協作邀請，接受後即可閱讀串接文件。

### 加入前請先準備

- **GitHub 帳號**：建議使用公司信箱註冊，方便識別與日後交接。
- **雙重驗證（2FA）**：本組織要求所有成員與協作者開啟 GitHub 雙重驗證。未開啟者無法存取文件，並可能被移出協作名單。設定方式請參考 [GitHub 官方說明](https://docs.github.com/zh/authentication/securing-your-account-with-two-factor-authentication-2fa/configuring-two-factor-authentication)。

### 存取權限的維護

- 技術窗口離職或異動時，請會員代表儘速至會員平台更新，公會將同步移除原人員的存取權限。
- 公會可能定期請會員代表確認技術窗口名單，逾期未確認者將暫停存取權限。

## 使用規範

閱讀或使用本組織內的任何文件與程式，即表示您同意遵守下列規範：

1. **僅供串接使用**：文件與範例程式僅限用於貴公司系統串接公會平台之開發、測試與維運。
2. **不得外流**：請勿將文件內容轉載、公開張貼、上傳至公開倉庫或提供給非授權人員。
3. **著作權**：文件內容之著作權屬原作者所有，經授權由公會提供會員使用。詳細授權條款請見各倉庫內的著作權聲明。
4. **金鑰保管**：串接時使用的 API 金鑰屬機密資料，請勿寫入程式碼、提交到任何倉庫，或貼在公開場合。
5. **個人資料保護**：透過 API 取得的資料若含個人資料，應依《個人資料保護法》及相關規定妥善處理。

## 回報問題

- **一般問題、文件錯誤或建議**：請寄信至秘書處 [secretary@tpfa.org.tw](mailto:secretary@tpfa.org.tw)，信件主旨請註明「API 串接」及貴公司名稱。
- **資安問題**：若您發現可能的安全漏洞，**請勿公開張貼**，請直接寄信至秘書處，信件主旨請註明「資安通報」。我們會儘速與您聯繫。
